# ResumeIQ Frontend - React + TypeScript + Tailwind CSS

The frontend dashboard for **ResumeIQ**, built with Vite, React 18, TypeScript, Tailwind CSS (Glassmorphism theme), and Lucide Icons.

## Features

- **Drag-and-Drop PDF Upload**: Live drag over state, size validation (max 5MB), and PDF metadata preview.
- **Glassmorphism Dark Theme Dashboard**: Neon cyan and purple radial score gauges, progress bars, and responsive card grid layout.
- **ATS Score Out of 100**: Breakdown into 7 scoring pillars (Contact, Skills, Experience, Education, Projects, Verbs, Formatting).
- **Skill Gap & Keyword Match**: Compares resume text against target Job Descriptions with missing vs matched badges.
- **Categorized Technical Skills**: Displays badges for Programming, Frameworks, Databases, DevOps, Tools, and Soft Skills.
- **Bonus AI Features**: Executive summary generator, tailored technical interview questions, and bullet point optimizer.
- **Exporting Options**: Export analysis as PDF report or downloadable JSON file.
- **Demo Mode**: 1-click sample resume loader for testing.

## Setup & Running

1. **Navigate to frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install Node.js Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.
